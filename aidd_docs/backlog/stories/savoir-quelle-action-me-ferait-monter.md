# Story: Savoir quelle action me ferait monter

**As** un développeur évalué
**I want** recevoir, par axe sous le cran suivant, l'action manquante et la preuve qui la validerait
**So that** je reparte avec quelque chose que je peux faire et vérifier

## Acceptance

- Chaque action est concrète et vérifiable : poser une boucle de relance se vérifie, améliorer son harness ne se vérifie pas.
- Chaque action nomme la preuve qui la validerait.
- Le texte des actions vient des données de la grille, pas du code.
- Aucun modèle n'est appelé pour produire ce texte.
