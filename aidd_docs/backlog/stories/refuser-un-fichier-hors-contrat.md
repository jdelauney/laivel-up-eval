# Story: Être refusé avec sa raison quand mon fichier est hors contrat

**As** un développeur évalué
**I want** savoir ce qui cloche quand un fichier n'est pas accepté
**So that** je ne reste pas devant un échec muet avec un fichier que je crois valide

## Acceptance

- Un fichier hors contrat est refusé en nommant le champ fautif.
- Aucun fichier n'est accepté partiellement ni réparé en silence.
- Le refus n'efface pas la partie en cours dans le navigateur.
