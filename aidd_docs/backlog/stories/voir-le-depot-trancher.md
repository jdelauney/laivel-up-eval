# Story: Voir le dépôt trancher quand il contredit mon parcours

**As** un développeur évalué
**I want** savoir laquelle des deux sources a décidé sur un axe
**So that** je comprenne pourquoi le verdict ne suit pas ce que j'ai fait dans les jeux

## Acceptance

- Sur un axe où les deux sources parlent, le cran du dépôt est retenu.
- Le cran écarté reste visible dans la trace, avec sa source.
- Quand seul le parcours parle, son cran est retenu avec une confiance moindre, affichée.
