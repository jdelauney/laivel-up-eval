# Story: Repérer ce qui est ambigu dans un prompt mal formulé

**As** un développeur évalué
**I want** surligner les segments d'un prompt qui laissent une marge d'interprétation
**So that** on mesure si je vois l'ambiguïté avant que l'IA ne l'exploite

## Acceptance

- Les segments réellement problématiques sont connus à l'avance et ne sont pas signalés au joueur.
- Le critère « part de segments identifiés au-dessus du seuil » ressort satisfait ou manqué.
- Surligner tout le prompt ne satisfait pas le critère.
