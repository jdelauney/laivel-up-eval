# Story: Recharger une partie pour la reprendre ou la rejouer

**As** un développeur évalué
**I want** repartir d'un fichier plutôt que du stockage de mon navigateur
**So that** je puisse continuer sur une autre machine, ou prouver que le verdict est reproductible

## Acceptance

- Une partie terminée rechargée rend exactement le même verdict, au caractère près.
- Une partie interrompue rechargée reprend au jeu suivant, pas au début.
- Le rechargement passe par le même port de persistance que le stockage navigateur.
