# Story: Compléter un prompt à qui il manque l'essentiel

**As** un développeur évalué
**I want** remplir les trous d'un prompt privé de son contexte, de sa contrainte ou de son format de sortie
**So that** on mesure si je sais ce qu'un prompt doit porter pour être exécutable

## Acceptance

- Les trous portent sur des éléments critiques, jamais sur du décor.
- Le critère « éléments critiques remplis correctement » ressort satisfait ou manqué.
- Un remplissage plausible mais hors sujet ne satisfait pas le critère.
