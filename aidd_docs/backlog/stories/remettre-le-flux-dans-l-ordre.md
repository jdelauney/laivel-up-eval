# Story: Remettre les étapes d'un flux AIDD dans l'ordre

**As** un développeur évalué
**I want** ordonner sur une frise les étapes qui vont du cadrage au merge
**So that** on mesure si je sais où se place chaque geste dans le flux

## Acceptance

- La frise accepte un ordre exact et un ordre presque juste à une position près.
- Les deux critères sont distincts et évalués séparément.
- Une inversion entre deux étapes voisines n'est pas notée comme une inversion de bout en bout.
