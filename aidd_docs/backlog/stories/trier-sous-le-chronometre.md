# Story: Trier des pratiques de sécurité sous le chronomètre

**As** un développeur évalué
**I want** glisser chaque pratique vers garder ou jeter avant la fin du temps, sans validation immédiate
**So that** on mesure ce que je sais sans le temps de le chercher

## Acceptance

- Aucune validation n'apparaît avant la fin : le chronomètre remplace le retour immédiat.
- Le critère « taux de bon classement au-dessus du seuil » ressort satisfait ou manqué.
- Le critère « tri bouclé dans le temps imparti » ressort satisfait ou manqué.
- Les éléments non triés à la fin comptent comme manqués, pas comme neutres.
