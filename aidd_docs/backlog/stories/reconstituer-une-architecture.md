# Story: Reconstituer une architecture à partir de fragments mélangés

**As** un développeur évalué
**I want** assembler des fragments dont l'ordre et les dépendances comptent
**So that** on mesure si je vois le système avant d'en écrire une ligne

## Acceptance

- Les fragments arrivent mélangés, et certaines pièces dépendent d'autres.
- Le critère « reconstitué sans erreur d'ordre » ressort satisfait ou manqué.
- Le critère « dépendances entre pièces respectées » ressort satisfait ou manqué, indépendamment de l'ordre.
