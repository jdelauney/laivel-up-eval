# VCS

## Setup

- Branche principale : `main`
- Plateforme : GitHub — `jdelauney/laivel-up-eval`, dépôt public sous licence MIT

## Branches

- Format : `type/description-courte`
- Types : `feat`, `fix`, `chore`, `ci`, `test`, `refactor`, `docs`

## Commits

- Convention : Conventional Commits
- Format : `type(scope): description`
- Règles : impératif, minuscules, description courte. Historique en anglais.

## Granularité

Une PR par jeu — le format week-end le permet et l'historique reste lisible pour le jury, qui le regarde. Chaque PR déclenche une preview GitHub Pages.

## Contrainte de rendu

**Aucune clé d'API, ni dans le code ni dans l'historique.** C'est un critère éliminatoire du sujet, vérifié sur l'historique complet avant le rendu.

## Stratégie de commit

L'IA committe : `after task done`
