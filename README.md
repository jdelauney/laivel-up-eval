# Laivel Up Eval

Projet de benchmark et d'évaluation pour des jeux de type "laivel" (ou "level up") afin d'analyser les performances, les mécaniques et les retours utilisateur.

## Description du projet

Laivel Up Eval vise à fournir une base simple pour tester et comparer plusieurs jeux ou scénarios d'entraînement, avec une approche orientée qualité, progression et analyse des résultats.

Le projet peut servir à :
- organiser des jeux ou mini-jeux de validation,
- évaluer des comportements ou des performances,
- suivre une progression sur plusieurs niveaux,
- préparer un cadre de démonstration ou de benchmark technique.

## Jeux disponibles

Le projet est conçu pour supporter plusieurs jeux ou expériences, dont :

- Jeu 1 : quiz de connaissances
- Jeu 2 : défi de rapidité et précision
- Jeu 3 : simulation de progression / montée de niveau
- Jeu 4 : mini-jeu de gestion ou de stratégie
- ...

## Installation

Prérequis :
- Node.js 18 ou plus
- npm ou yarn

Étapes :
1. Clonez le dépôt :
   ```bash
   git clone https://github.com/jdelauney/laivel-up-eval.git
   cd laivel-up-eval
   ```
2. Installez les dépendances :
   ```bash
   npm install
   ```
3. Lancez le projet :
   ```bash
   npm run dev
   ```

Si le projet utilise un autre script, vérifiez le fichier package.json pour le bon nom de commande.
